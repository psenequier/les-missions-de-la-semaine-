# Signaler une faille

Ce dépôt est public. Les données des familles sont dans Supabase, protégées par des règles
qui séparent chaque famille (voir `supabase/schema.sql`).

Si vous trouvez une faille, ne l'exposez pas dans un ticket ou une pull request publique.
Utilisez le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**.
L'administrateur répond sous sept jours.

Le scan actif (ZAP) ne vise que la copie du site servie dans la CI. Merci de ne pas tester le site en ligne.
